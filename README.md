
# Autism Classification Model Evaluation

## Project Overview

This project evaluates whether machine-learning models can identify patterns associated with caregiver-reported history of an autism spectrum disorder (ASD) diagnosis using the 2022 National Survey of Children's Health (NSCH) topical dataset.

**Important:** The target represents caregiver-reported survey status, not a verified clinical diagnosis. This project is for educational model evaluation only and must not be used to diagnose or screen individual children.

## Dataset

- Source: 2022 National Survey of Children's Health (NSCH) topical dataset.
- Input ZIP file: `nsch_2022_topical_Stata.zip`
- Stata file inside the ZIP: `nsch_2022e_topical.dta`
- Original dataset: 54,103 rows and 484 columns.
- Records after filtering valid `k2q35a` responses: 53,825.
- Target: `k2q35a`, mapped as `1 -> 1` and `2 -> 0`.
- Class 0: 51,917 records (approximately 96.5%).
- Class 1: 1,908 records (approximately 3.5%).

The raw dataset is not included in this GitHub repository. Obtain the dataset from the appropriate NSCH source and upload the ZIP when running the notebook in Google Colab.

## Models and Workflow

The notebook:

1. Loads the NSCH Stata dataset.
2. Inspects the target-question response codes.
3. Creates a binary target variable.
4. Excludes autism-related and `k2q35` variables, as well as `hhid` and `fwc`, from model inputs to reduce target leakage.
5. Splits the data into stratified training and testing sets.
6. Imputes missing values, scales numerical features, and encodes categorical features.
7. Compares baseline Logistic Regression and Random Forest models.
8. Tunes Logistic Regression using stratified three-fold cross-validation and average precision.
9. Trains a TensorFlow/Keras neural network using dropout and early stopping.
10. Evaluates models using classification metrics, ROC curves, confusion matrices, and neural-network learning curves.
11. Saves the tuned Logistic Regression pipeline and trained neural network.

## Evaluation

Because the positive class represents only about 3.5% of the filtered dataset, accuracy alone can be misleading. Precision, recall, F1-score, average precision, ROC-AUC, and confusion matrices should be interpreted together.

Run the notebook from top to bottom in Google Colab. Report the metrics generated by a fresh, successful run rather than relying on old notebook outputs.

## Limitations

- The target is caregiver-reported diagnosis history, not a clinical assessment.
- The positive class is substantially underrepresented.
- Missing data, survey limitations, and feature selection may affect performance.
- Results on this dataset do not guarantee performance on other populations.
- The models must not be used for diagnosis, individual screening, or clinical decisions.
