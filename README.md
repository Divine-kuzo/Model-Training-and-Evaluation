
# Autism Classification Model Evaluation

## Project Overview

This project evaluates whether machine-learning models can identify patterns associated with caregiver-reported history of an autism spectrum disorder (ASD) diagnosis using the 2022 National Survey of Children's Health (NSCH) topical dataset.

**Important:** The target represents caregiver-reported survey status, not a verified clinical diagnosis. This project is for educational model evaluation only and must not be used to diagnose or screen individual children.
